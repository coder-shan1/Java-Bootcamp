## 📚 Topics Covered

### 1. Core Java

The foundation of Java programming including variables, data types, loops, OOP concepts (Encapsulation, Inheritance, Polymorphism, Abstraction), and basic problem-solving.

### 2. Maven

A build automation tool used to manage project dependencies, compile code, and package applications efficiently.

### 3. Gradle

Another build tool that is faster and more flexible than Maven, using Groovy/Kotlin DSL for configuration.

### 4. JUnit

A testing framework used to write and run automated tests to ensure code quality and correctness.

### 5. Git

Version control system to track code changes, collaborate, and manage project history.

### 6. Data Structures & Algorithms (DSA)

Essential concepts like arrays, linked lists, stacks, queues, trees, and sorting/searching algorithms for problem-solving.

### 7. JDBC

Java Database Connectivity used to connect Java applications with databases and perform CRUD operations.

### 8. Servlets & JSP

Technologies used to build dynamic web applications using Java on the server side.

### 9. REST APIs & Web Services

Designing APIs that allow communication between systems using HTTP methods like GET, POST, PUT, DELETE.

### 10. ORM Tools

Object Relational Mapping tools simplify database interaction by mapping Java objects to database tables.

### 11. Hibernate

A popular ORM framework that reduces boilerplate code for database operations.

### 12. Spring Framework

A powerful framework for building enterprise Java applications with dependency injection and modular design.

### 13. Spring Boot REST API

Simplifies Spring development and helps build REST APIs quickly with minimal configuration.

### 14. Spring JDBC

Spring module that simplifies database interaction using JDBC with better exception handling.

### 15. Spring Data JPA

Provides abstraction over JPA to reduce boilerplate code for database operations.

### 16. Spring Boot MVC Project

Building a complete web application using Model-View-Controller architecture.

### 17. Spring Security

Handles authentication and authorization to secure applications.

### 18. JWT (JSON Web Token)

Used for secure authentication by exchanging tokens between client and server.

### 19. OAuth2

Authorization framework that allows secure access to resources without sharing credentials.

### 20. Log4j

Logging framework to track application behavior and debug issues.

### 21. Spring Boot + MongoDB

Building applications using NoSQL database (MongoDB) with Spring Boot.

### 22. Docker

Containerization tool to package applications and run them consistently across environments.

### 23. Cloud Deployment

Deploying applications on cloud platforms like AWS, Azure, or GCP.

### 24. Spring AI

Integrating AI capabilities into Spring applications.

### 25. DeepSeek + Ollama

Running open-source AI models locally and integrating them with Java applications.

### 26. Microservices

Breaking applications into small independent services for scalability and maintainability.

### 27. Spring Boot + Kafka

Using Kafka for real-time data streaming and communication between services.

### 28. Linux

Basic commands and system operations for development and deployment environments.

### 29. Ansible

Automation tool for configuration management and deployment.

### 30. Jenkins

CI/CD tool to automate build, test, and deployment pipelines.

### 31. Terraform

Infrastructure as Code tool to manage cloud resources efficiently.
